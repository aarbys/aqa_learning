# Automated Quality Assurance (AQA) Learning

Репозиторий содержит учебный проект по автоматизации тестирования (AQA) API с использованием языка Python и фреймворка Pytest.

## 🛠️ Технологический стек
* **Python 3.10+** — основной язык разработки.
* **Pytest** — фреймворк для написания, структурирования и запуска автотестов.
* **Requests** — библиотека для отправки HTTP-запросов к API.
* **Pydantic / Models** — валидация данных и описание структур ответов API.

## 📁 Структура проекта
* `api/` — методы для работы с эндпоинтами, базовые HTTP-клиенты и обёртки для запросов.
* `models/` — дата-классы или Pydantic-модели для проверки схем ответов API.
* `tests/` — тест-кейсы (функциональные, позитивные и негативные сценарии).
* `config.py` — конфигурационные файлы проекта (URL стендов, токены, настройки окружения).
* `conftest.py` — фикстуры Pytest для настройки предусловий (setup/teardown), инициализации клиентов или создания тестовых данных.

## 🚀 Настройка окружения и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd aqa_learning
```

### 2. Создание и активация виртуального окружения
* **Windows (PowerShell):**
  ```bash
  python -m venv .venv
  .venv\Scripts\Activate.ps1
  ```
* **Linux / macOS:**
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  ```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск тестов
* **Запуск всех тестов:**
  ```bash
  pytest
  ```
* **Запуск с подробным выводом (verbose):**
  ```bash
  pytest -v
  ```
